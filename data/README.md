# Data

This project expects `data/netflix_titles.csv` — the Kaggle
[Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
dataset.

## Getting the real dataset

1. Download `netflix_titles.csv` from the Kaggle link above (requires a free
   Kaggle account), or via the Kaggle CLI:
   ```bash
   kaggle datasets download -d shivamb/netflix-shows -p data --unzip
   ```
2. Place the CSV at `data/netflix_titles.csv`.

## No Kaggle account? No problem

If `data/netflix_titles.csv` is missing, every entry point (`app.py`, the
notebook, the test suite) automatically falls back to a synthetic sample
dataset with the same schema, generated by `src/generate_sample_data.py`.
This keeps the project runnable out of the box, but the sample data is
randomly generated and does **not** reflect real-world patterns — swap in
the real CSV for genuine analysis.

To generate the sample CSV to disk explicitly:

```bash
python -m src.generate_sample_data
```
